# skille-pl

Skille do Agent Skills (Google AI Edge Gallery) po polsku i norwesku.

- `nauka-pl/` - wyjaśnia temat po polsku w stałym formacie
- `nauka-no/` - to samo po norwesku
- `learn-something-new-pl/` - polska wersja oficjalnego skilla Google „Learn Something New”, z wyszukiwaniem w polskiej Wikipedii, kartą graficzną i opcjonalnym przypomnieniem
